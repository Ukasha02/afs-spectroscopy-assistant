# A04 · First technical assessment

**Decision status.** Premise not supported / concept not approved. The wheat model transfer is contradicted by the materials; not approved for rye or oat flour.

**Requirements stated.** An NIR moisture model exists, built for wheat flour; Rye and oat flour are now also milled; Supplier states water absorbs the same in every flour; Use on the new flours is wanted next week.

**Key unknowns.** Moisture range of rye and oat versus wheat; Reference method and its uncertainty; Particle size, bran and presentation of the new flours; Accuracy, acceptance limit and response time.

### Clarification questions

1. Which moisture ranges do rye and oat flour have versus the wheat calibration range?
2. Which reference method and uncertainty apply, and can reference-analysed rye and oat samples be supplied?
3. How do particle size, bran and storage differ between the flours and batches?
4. What accuracy, response time and acceptance limit apply, is next week fixed, and how are samples presented?

### Recommendation

- **Premise: The existing wheat flour NIR moisture model will work on rye and oat flour.** — contradicted. Calibrations are matrix-specific, so a wheat model is not transferable by default [DOCX §5].
- **Premise: Water absorbs the same way in every flour, so the signal relation is identical.** — unverifiable. No source gives water absorption data for rye, oat or wheat flour; a spectral check is needed. *(assumption)*
- **Premise: The existing model can be used on the new flours starting next week.** — unverifiable. No timing or validation evidence exists; use depends on the lab check. *(assumption)*
- **NIR spectroscopy (Diffuse reflection probe for powder).** An NIR-LED moisture sensor example shows trans-flex or diffuse reflection options and flour spectra, though no powder moisture result [S02 p.12]. Calibration is matrix-specific and must be tested on rye and oat flour before use [DOCX §5].
- **Raman spectroscopy (Raman fiber probe for powder).** A Raman probe is a comparison candidate, shown for API potency in a feed frame, not moisture [S01 p.15]. Organic-compound fluorescence can swamp the weak Raman signal; check signal quality first [S01 p.11].

**Measurement concept.** Diffuse reflection probe for powder [S01 Table 1 (p.6)]. Measurement point unknown; wheat geometry assumed until confirmed. *(assumption)* No link defined. **Spectral range.** NIR: 780-2500 nm nominal [S01 p.10]; Raman: Raman shift in cm-1; signal recorded in 400-1100 nm nominal [S01 p.11] (Excitation wavelength stated separately; not set here). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- A matrix-specific calibration may not hold for rye and oat flour [DOCX §5].
- Particle size and bran differences can mimic moisture changes [DOCX §5].
- Neither the existing model nor the Raman comparison is guaranteed to predict moisture. *(assumption)*
- Accuracy, update rate, interface ratings and compatibility are unconfirmed. *(assumption)*

### First feasibility experiment

1. Collect rye and oat flour across the agreed moisture range and typical variation.
2. Record spectra with independent reference moisture results and timing.
3. Test the wheat model unchanged first; build a flour-specific model only if needed, validated on held-out batches.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree moisture error and bias limits with the client before testing; choose the simplest configuration meeting them on independent flour.
