### Recommendation

- **Premise plausible to be tested:** An optical measurement can detect API composition changes while the melt is processed [S02 p.14].
- **Premise unverifiable:** A probe can operate at the hot interface despite possible material build-up.
- **Premise unverifiable:** A fiber link can carry each candidate method's range [S02 p.6].
- **NIR spectroscopy (diffuse reflection probe at the die).** The AFS extrusion example places an NIR reflection probe at the die for API in hot polymer [S02 p.14]. Overlapping NIR bands suggest using chemometrics, so a calibration for this matrix would need to be built and tested [S01 p.10].
- **MIR (FTIR) spectroscopy (diamond ATR probe with PIR fiber).** The same slide shows API spectra in hot polymer from a diamond ATR probe with FTIR [S02 p.14]. ATR samples only about 1-6 um, so the signal reflects the layer at the probe surface [S01 Table 1 (p.6)].

**Measurement concept.** Diffuse reflection probe (listed for solids, powders) and MIR ATR probe (liquids, pastes, soft samples); suitability for hot melt must be verified on representative samples [S01 Table 1 (p.6)]. Near the die, as in the AFS extrusion example; exact point agreed with the client [S02 p.14]. No link stated; MIR needs an IR fiber such as chalcogenide or polycrystalline, not silica [S02 p.6]. Needs AFS confirmation: Probe temperature and pressure rating, Installation port at die, Window or crystal fouling control.

**Spectral range.** NIR spectroscopy: 780-2500 nm nominal [S01 p.10]; MIR (FTIR) spectroscopy: 4000-400 cm-1 nominal [S01 p.9]. Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- Since NIR relies on chemometrics, an API, polymer or formulation change may invalidate the calibration [S01 p.10] *(assumption)*.
- Temperature, bubbles, scattering or build-up may mimic composition changes. *(general knowledge)*
- Neither method is guaranteed to resolve this API. *(assumption)*
- Accuracy, update rate, probe ratings and compatibility are unconfirmed. *(assumption)*
- Link unknown; MIR-ATR cannot run over silica fiber [S02 p.6].

### First feasibility experiment

1. Prepare melt samples across the client-agreed API range, with temperature, feed and homogeneity variation.
2. Record NIR and MIR-ATR spectra with time-aligned offline assay results.
3. Build single-method models first; validate on held-out runs or batches.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria with the client beforehand; choose the simplest configuration meeting them on independent runs.
