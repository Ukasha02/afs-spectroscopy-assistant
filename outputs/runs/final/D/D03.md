# D03 · First technical assessment

**Decision status.** Provisional feasibility assessment. Target and matrix are defined; levels, turbidity range and reference are still open.

**Requirements stated.** Dairy process with a relatively clear whey stream before a concentration stage; Track protein concentration as the stream changes; Laboratory results serve as the reference; The stream can turn more turbid; the concept must handle this.

**Key unknowns.** Protein level and range; Turbidity range and its causes; Reference method, uncertainty and sampling timing; Installation point, accuracy, response time and cleaning.

2. Which lab protein method is used, with what uncertainty, and how is sampling timed?
3. Which operating conditions cause turbidity, how strong does it get, and do temperature or composition vary?
4. What accuracy, response time, installation point, contact and cleaning (CIP) constraints apply?

### Recommendation

- **Premise plausible to be tested:** Spectroscopy can track protein concentration in the whey stream as it changes [S01 p.18; S01 p.17].
- **Premise unverifiable:** Laboratory results are a suitable reference for calibration.
- **NIR spectroscopy (transmission / transflection probe).** The dairy example supports transmission or transflection for whey, and transflection may cover clear and turbid states [S01 p.18]. Transmission fails when the sample becomes too thick, so path length must be tested against the turbid states [S01 p.18].
- **NIR spectroscopy (diffuse reflection probe).** The dairy example supports reflection for opaque or concentrated products, which suits the turbid operating states [S01 p.17]. Reflection can be less representative for clear liquids, so test it only if transflection fails in turbid states [S01 p.18].

**Measurement concept.** NIR transmission/transflection probe with a defined path length; NIR diffuse reflection probe as the comparison for turbid states [S01 Table 1 (p.6)]. In the whey line before the concentration stage, where time-aligned reference samples can be drawn. No fiber link stated. Rule check: NIR: Vis-NIR silica partial (0.78-2.4 um) [S02 p.6; S01 p.10]. Needs AFS confirmation: Probe type and path length, Installation and CIP compatibility, Optical configuration.

**Spectral range.** NIR spectroscopy: 780–2500 nm nominal [S01 p.10]. Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- NIR calibrations are matrix-specific; a composition or matrix change can invalidate them [DOCX §5].
- Turbidity and scattering changes can mimic protein changes [S01 p.17].
- Neither geometry is guaranteed to follow protein across all states. *(assumption)*
- Accuracy, update rate, interface ratings and equipment compatibility are unconfirmed. *(assumption)*
- Fouling of the probe window may drift the signal. *(general knowledge)*

### First feasibility experiment

1. Collect whey samples across the client-agreed protein range, including clear and turbid operating states.
2. Record transflection and reflection NIR spectra with time-aligned lab protein references.
3. Build single-method models first, one per geometry; a combined model only if justified; validate on held-out production runs.
4. Compare prediction error, bias and the ability to follow changes against the client's requirements.

**Decision basis.** Agree numerical acceptance criteria with the client before testing. Choose the simplest geometry that meets them on independent runs.
