# D03 · First technical assessment

**Decision status.** Provisional feasibility assessment. Target and matrix defined; protein range, turbidity and requirements unknown.

**Requirements stated.** Relatively clear whey stream before a concentration stage; Track protein concentration as the stream changes; Laboratory results are the reference; Stream can become more turbid.

**Key unknowns.** Protein range and level; Turbidity range and causes; Reference method and uncertainty; Accuracy, response time, installation, cleaning.

### Clarification questions

1. Which protein range and level occur, and which changes must be distinguished?
2. Which lab protein method, uncertainty and sampling timing provide the reference?
3. What causes turbidity, and how do temperature, fat and particles vary?
4. What accuracy, response time, installation point and cleaning regime apply?
5. Which concentration-stage decision should the protein data drive?

### Recommendation

- **Premise plausible to be tested:** Spectroscopy can track protein concentration in the whey stream as it changes [S01 p.18; S01 p.17].
- **Premise plausible to be tested:** One measurement concept can handle both the clear and the more turbid state [S01 p.18].
- **Premise unverifiable:** Laboratory results are a suitable reference for calibration.
- **NIR spectroscopy (transmission / transflection probe).** The dairy example supports NIR transmission for whey [S01 p.18]. Path length must suit turbid states; transflection as a combined solution needs testing [S01 p.18].
- **NIR spectroscopy (diffuse reflection probe).** The dairy example supports NIR reflection for opaque or concentrated products [S01 p.17]. Reflection is surface-sensitive and less representative for clear liquids [S01 p.17; S01 p.18].

**Measurement concept.** NIR transmission/transflection probe, path length set on clear and turbid samples; diffuse reflection probe as comparison [S01 Table 1 (p.6); S01 p.18]. In the whey line before the concentration stage; exact point to be confirmed with the client. No link stated; silica fibers cover UV/Vis and NIR [S02 p.6]. Needs AFS confirmation: probe type and path length, installation point and mounting, cleaning compatibility.

**Spectral range.** NIR spectroscopy: 780-2500 nm nominal [S01 p.10] (Nominal only; usable bands follow from sample spectra). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- NIR quantification relies on PLS calibrations, which need rechecking when the matrix changes [S01 p.10; S01 p.17].
- Turbidity scattering interferes with spectra; strong turbidity blocks transmission [S01 p.17; S01 p.18].
- Neither geometry is guaranteed to cover clear and turbid states. *(assumption)*
- Accuracy, update rate, probe ratings and compatibility are unconfirmed. *(assumption)*
- Protein deposits on probe windows could cause drift. *(general knowledge)*

### First feasibility experiment

1. Collect samples across the client-agreed protein range, covering clear, turbid and temperature variation.
2. Record transflection and reflection spectra with time-aligned independent laboratory protein results.
3. Build single-method models per geometry first; validate on held-out runs including turbid states.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria with the client before the test; choose the simplest geometry that meets them on independent runs.
