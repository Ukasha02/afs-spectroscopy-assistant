# D01 · First technical assessment

**Decision status.** Provisional feasibility assessment. Target and matrix are defined; API level, limits and reference details are open.

**Requirements stated.** Tablets from an API and excipient powder blend; Lab results arrive after material passes the press; Follow API concentration changes in the feed frame via fiber; Pilot compares options before buying production equipment.

**Key unknowns.** API, excipients, target level, limits; Reference assay, uncertainty, timing; Blend physical variation; Response time, access, cleaning.

### Clarification questions

1. Which API, excipients and target range, and which changes must be detected?
2. Which assay gives reference values, with what uncertainty and sampling time?
3. How do particle size, density, lots and flow vary between batches?
4. What response time, limits, probe access and cleaning constraints apply?
5. Which decision would real-time API data drive?

### Recommendation

- **Premise plausible to be tested:** A fiber-based measurement in the feed frame could follow API concentration changes [S01 p.15].
- **NIR spectroscopy (diffuse reflection probe).** A published feed frame study on a different blend used an NIR reflection probe [S01 p.15]. A chemometric calibration must be built and tested on this blend [S01 p.10].
- **Raman spectroscopy (Raman contact probe).** The same published study used a Raman contact probe; comparison candidate [S01 p.15]. Check fluorescence background and weak signal; cost is rated high [S01 p.11; S01 Table 1 (p.6)].
- **NIR + Raman (combined probe at one spot).** That study reports complementary information from NIR and Raman [S01 p.15]. Only after each method is assessed alone; any gain is a hypothesis to test.

**Measurement concept.** Table 1 lists powder among sample types for the NIR diffuse reflection probe and the Raman probe [S01 Table 1 (p.6)]. Feed frame of the tablet press, as the client stated. No fiber link stated; silica fibers suit UV/Vis, NIR and Raman, while MIR needs IR fibers [S02 p.6]. Needs AFS confirmation: probe type, feed frame installation, optical configuration.

**Spectral range.** NIR: 780–2500 nm nominal [S01 p.10]; Raman: Raman shift (cm-1); signal 400–1100 nm nominal [S01 p.11] (Excitation wavelength stated separately; to be selected). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- API, excipient or formulation changes can invalidate a calibration. *(general knowledge)*
- Particle size, density and flow changes can mimic composition. *(general knowledge)*
- Neither method nor the combination is guaranteed to help. *(assumption)*
- Accuracy, update rate, probe ratings and compatibility are unconfirmed. *(assumption)*
- Powder build-up on the probe window may degrade signal. *(general knowledge)*

### First feasibility experiment

1. Prepare blends across the client-agreed API range, including particle size, lot and flow variation.
2. Record NIR and Raman spectra with independent, time-aligned API assays.
3. Build single-method models first, fused only if justified; validate on held-out batches.
4. Compare prediction error, bias and ability to follow API changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria with the client before testing; choose the simplest configuration meeting them on independent batches.
