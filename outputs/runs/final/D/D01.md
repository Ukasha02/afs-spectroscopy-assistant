### Recommendation

- **Premise plausible to be tested:** A fiber-based measurement in the feed frame could follow API concentration changes [S01 p.15; DOCX §3].
- **NIR spectroscopy (diffuse reflection probe).** The feed-frame potency example uses an NIR reflection probe [S01 p.15]. Overlapping bands suggest chemometrics; a blend-specific calibration would need building and testing [S01 p.10].
- **Raman spectroscopy (Raman contact probe).** The same example uses a Raman contact probe [S01 p.15]. Fluorescence background can swamp the weak Raman signal; check signal quality first [S01 p.11].
- **NIR + Raman (two probes or combi probe at the same spot).** For feed-frame blends, NIR and Raman capture complementary chemical information [S01 p.15]. Only after each method is assessed alone; the gain is a hypothesis to test [DOCX §5].

**Measurement concept.** NIR diffuse reflection and Raman probes, both rated for powders [S01 Table 1 (p.6)]. In the feed frame where the blend passes the probe; mounting point to be agreed. No fiber link stated. Rule check: NIR: Vis-NIR silica partial (0.78-2.4 um); RAMAN: Vis-NIR silica covers the nominal range [S02 p.6; S01 p.10; S01 p.11]. Needs AFS confirmation: Probe type and window, Feed-frame installation, Optical configuration.

**Spectral range.** NIR spectroscopy: 780–2500 nm nominal [S01 p.10]; Raman spectroscopy: Raman shift (cm-1) nominal [S01 p.11] (Excitation separate; feed-frame example used 785 nm). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- Formulation changes can invalidate a calibration [DOCX §5].
- Particle size, density or flow changes can mimic composition [DOCX §5].
- No method or combination is guaranteed to help [DOCX §5].
- Accuracy, update rate, interface ratings and compatibility are unconfirmed [DOCX §3].
- Fiber link undefined; its range coverage needs confirmation. *(assumption)*

### First feasibility experiment

1. Prepare blends across the client-agreed API range and relevant physical and batch variation.
2. Record NIR and Raman spectra with time-aligned independent API reference assays.
3. Single-method models first, combined only if justified; validate on held-out batches.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical criteria with the client beforehand; choose the simplest configuration meeting them on independent batches.
