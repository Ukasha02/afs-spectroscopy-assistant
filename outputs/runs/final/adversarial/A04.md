# A04 · First technical assessment

**Decision status.** Premise not supported / concept not approved. A wheat-flour calibration cannot be assumed valid for rye and oat.

**Requirements stated.** NIR moisture model built for wheat flour; Rye and oat flour now also milled; Supplier says the model transfers because water absorbs alike; Wants to use it on the new flours next week.

**Key unknowns.** Moisture range and required accuracy per flour; Reference method and its uncertainty; Physical and compositional differences between flours; Any existing rye or oat test data.

### Clarification questions

1. Which moisture range occurs in rye and oat flour, and which differences must be resolved?
2. Which reference moisture method, uncertainty and sampling time apply to each flour?
3. How do particle size, density, composition and temperature differ between flours and batches?
4. Has the wheat model been tested on rye or oat, and with what results?
5. What accuracy, response time and installation point apply, and what decision does moisture drive?

### Recommendation

- **Premise contradicted:** The wheat-flour NIR moisture model will work for rye and oat flour without recalibration [DOCX §5; S01 p.10].
- **Premise plausible to be tested:** Water absorbs the same way in every flour.
- **Premise unverifiable:** The existing model can be used on the new flours next week.
- **NIR spectroscopy (diffuse reflection (existing instrument), with flour-specific calibration).** An AFS slide shows a customised-calibration NIR-LED moisture concept (wood demo) and flour spectra; this is a reason to test, not validation for bulk flour [S02 p.12]. A rye and oat calibration, or an extended model, must be built and validated against reference moisture before use [DOCX §5].

**Measurement concept.** NIR diffuse reflection probe, listed for scattering media and powders, as a general option to test on all flours [S01 Table 1 (p.6)]. The existing measuring point is assumed for all flours, pending confirmation of whether presentation differs. *(assumption)* No fiber link stated. The nominal NIR range (780–2500 nm) only partly overlaps Vis-NIR silica fiber transmission (350–2400 nm); actual fiber and probe need datasheet confirmation [S01 p.10; S02 p.6]. No fiber link stated. Rule check: NIR: Vis-NIR silica partial (0.78-2.4 um) [S02 p.6; S01 p.10]. Needs AFS confirmation: Probe type and geometry, Installation and sample presentation, Instrument usable spectral range.

**Spectral range.** NIR spectroscopy: 780–2500 nm nominal [S01 p.10]. Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- Changing flour type can invalidate the wheat calibration and bias moisture results [DOCX §5].
- Particle size, packing and temperature differences can mimic moisture changes [DOCX §5].
- A joint model for all flours is not guaranteed to match separate models. *(assumption)*
- Accuracy, update rate and setup suitability for rye and oat are unconfirmed. *(assumption)*
- The AFS moisture slide is a reason to test, not proof for this mill [S02 p.12; DOCX §3].

### First feasibility experiment

1. Collect rye and oat batches across the client-agreed moisture range and the normal physical and process variation.
2. Record NIR spectra with time-aligned independent reference moisture values for each sample.
3. First test the wheat model as is, then flour-specific or extended models. Validate on held-out batches.
4. Compare prediction error, bias and the ability to follow moisture changes against the client's requirements.

**Decision basis.** Agree numerical acceptance criteria with the client before testing. Adopt the simplest model that meets them on independent rye and oat batches.
