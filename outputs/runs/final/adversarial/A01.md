# A01 · First technical assessment

**Decision status.** Premise not supported / concept not approved. Chalcogenide IR fiber does not transmit the UV/Vis range.

**Requirements stated.** Coloured by-product followed in a fermenter by UV/Vis absorbance; Spectrometer to move to the control room; Reuse leftover chalcogenide IR fiber from an FTIR project as link.

**Key unknowns.** By-product identity, level, wavelength; Broth clarity, cell content; Link distance; Reference method, requirements, cleaning or sterilization.

### Clarification questions

1. Which by-product, level and wavelength, and which changes must be distinguished?
2. Which reference method, uncertainty and sampling time check the by-product?
3. How do broth clarity, cells, bubbles and temperature vary between runs?
4. What accuracy, response time, sterilization and installation limits apply?
5. How far is the control room, and what drives the move?

### Recommendation

- **Premise contradicted:** The leftover chalcogenide (CIR) fiber can link the probe to the UV/Vis spectrometer [S02 p.6].
- **Premise unverifiable:** A fiber link can bridge the distance from the fermenter to the control room.
- **Premise plausible to be tested:** The UV/Vis method keeps its performance after moving the spectrometer [S01 p.2].
- **UV/Vis absorbance over UV-Vis silica fiber (transmission or transflection probe).** The bioprocess example supports UV transmission or transflection probes for clear, low-OD media [S01 p.16]. Needs a UV-Vis silica link instead of the CIR cable; overlapping UV signals may need chemometrics [S02 p.6; S01 p.5].
- **UV/Vis absorbance (UV-ATR probe).** The same example supports UV-ATR for opaque or turbid media [S01 p.16]. Only if the broth saturates transmission; UV-ATR is rated low sensitivity [S01 Table 1 (p.6)].

**Measurement concept.** UV/Vis transmission or transflection probe in the broth; UV-ATR only if too opaque [S01 Table 1 (p.6); S01 p.16]. Probe in the fermenter, spectrometer in the control room. Rule check of the stated fiber: UVVIS: Chalcogenide As-S IR fiber (CIR) none [S02 p.6; S01 p.5]. Needs AFS confirmation: UV-Vis fiber over link length, Probe sterilization compatibility, Probe path length.

**Spectral range.** UV/Vis absorbance: UV 190–360 nm and visible; depends on target and setup nominal [S01 p.5]. Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- The CIR cable cannot carry UV/Vis; link length is unknown [S02 p.6].
- Cell turbidity may raise absorbance and mimic the by-product. *(general knowledge)*
- Overlapping UV signals need chemometrics; calibration validity under broth changes must be verified [S01 p.5].
- Moving the spectrometer does not guarantee equal performance. *(assumption)*
- Accuracy, update rate, probe ratings and compatibility are unconfirmed. *(assumption)*

### First feasibility experiment

1. Collect broth samples across the agreed by-product range, growth stages and turbidity variation.
2. Record spectra through a UV-Vis silica link with time-aligned lab reference results.
3. Build a single-method model per probe geometry; validate on held-out fermentation runs.
4. Compare prediction error, bias and ability to follow changes against the client's requirements.

**Decision basis.** Agree numerical acceptance criteria with the client beforehand; choose the simplest configuration meeting them on independent runs.

**Sources.** S01 Table 1 (p.6), S01 p.16, S01 p.2, S01 p.5, S02 p.6.
