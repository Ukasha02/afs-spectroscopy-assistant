### Recommendation

- **Premise unverifiable:** The analyzer can be linked to the feed frame by fiber.
- **NIR spectroscopy (diffuse reflection probe).** The feed-frame blend-potency example names NIR as widely used [S01 p.15]. Overlapping bands call for chemometrics; a matrix-specific calibration must be developed and validated for this blend [S01 p.10; DOCX §5].
- **Raman spectroscopy (Raman fiber probe (contact)).** The same example uses a Raman contact probe; comparison candidate [S01 p.15]. Fluorescence background may dominate; cost rated high [S01 p.11; S01 Table 1 (p.6)].
- **NIR + Raman (combined probe or synchronized probes at the same spot).** The example reports fused NIR and Raman models outperforming single-method models [S01 p.15]. Only after each method is assessed alone; the gain is a hypothesis to test and needs synchronized data [S01 p.8; DOCX §5].

**Measurement concept.** NIR diffuse reflection probe and Raman probe for powder [S01 Table 1 (p.6)]. Feed frame of the tablet press. Vis-NIR silica reaches 2400 nm, not full NIR; Raman fiber fit depends on excitation and shift range; link undefined [S02 p.6; S01 p.11]. No fiber link stated. Rule check: NIR: Vis-NIR silica partial (0.78-2.4 um); RAMAN: Vis-NIR silica covers the nominal range [S02 p.6; S01 p.10; S01 p.11]. Needs AFS confirmation: probe type per method, feed-frame installation, fiber route and length.

**Spectral range.** NIR: 780–2500 nm nominal [S01 p.10]; Raman: Raman shift (cm-1); recorded at 400–1100 nm nominal [S01 p.11] (Example excitation 785 nm, separate from shift). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- A formulation change can invalidate a calibration [DOCX §5].
- Physical variation (particle size, density, flow) may mimic API changes; verify in tests [DOCX §5].
- No method or combination is guaranteed to meet requirements [DOCX §5].
- Accuracy, update rate, interface ratings and compatibility are unconfirmed [DOCX §3].
- Fiber family and link length are undefined. *(assumption)*

### First feasibility experiment

1. Prepare blends across the client-agreed API range with realistic particle, density and lubricant variation.
2. Record NIR and Raman spectra with time-aligned reference API assays.
3. Build single-method models first, fuse only if justified; validate on held-out batches.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria beforehand; choose the simplest configuration meeting them on independent batches.
