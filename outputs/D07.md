# D07 · First technical assessment

**Decision status.** Insufficient information. API named; polymer matrix, concentration and melt optical state unknown.

**Requirements stated.** Hot polymer extrusion process with an API; Question: does optical measurement detect composition changes during melt processing; Offline assays are available; Hot interface may build up material.

**Key unknowns.** API identity and ppm or % level; Polymer formulation and melt optical state; Reference assay accuracy and sampling timing; Build-up tolerance and cleaning routine.

### Clarification questions

1. Which API, polymer and concentration range (ppm or %) matter, and is the melt clear or opaque?
2. Which offline assay is the reference, with what accuracy and sampling time, and can samples be time-aligned?
3. How do melt temperature, texture, bubbles and homogeneity vary between runs; do earlier calibrations exist?
4. What response time, accuracy, installation point and build-up cleaning routine apply?
5. Is this production, pilot or research, and which GMP or quality standards govern it?

### Recommendation

- **Premise: An optical measurement can detect API composition changes during hot polymer extrusion.** — plausible to be tested. Same application type shown: API in hot polymer extrusion with NIR and MIR-ATR [S02 p.14]. A published example is a reason to test, not proof for this customer [DOCX §3].
- **Premise: The process interface can carry an optical probe despite heat and build-up.** — unverifiable. No source covers melt-interface build-up; test in the trial. *(assumption)*
- **NIR spectroscopy (Diffuse reflection probe at barrel or die).** NIR reflection probe at the extruder die is the shown API-in-extrusion example [S02 p.14]. Table 1 lists a 0.5-1 mm depth for the NIR diffuse reflection probe on scattering media and powders; melt depth is not given [S01 Table 1 (p.6)].
- **MIR (FTIR) ATR (Diamond ATR probe in contact with the melt).** Diamond ATR probe with FTIR was shown for API in hot polymer extrusion [S02 p.14]. ATR samples only about 1-6 um deep; contact and fouling need assessment, and PIR fibre is one fibre option for mid-IR [S01 Table 1 (p.6); S02 p.6].
- **NIR + Raman (Combined probe at the same spot).** Combined NIR and Raman was shown for API potency in a tablet press feed frame [S01 p.15]. Only after each method is assessed alone; gain for a melt is a hypothesis to test [DOCX §5].

**Measurement concept.** NIR diffuse reflection probe as in the die example; suitability for a melt is an assumption to test [S02 p.14] *(assumption)*. Barrel or die, as in the die example; not yet confirmed [S02 p.14]. Silica VIS-NIR fibre covers about 0.35-2.4 um; probe length not defined [S02 p.6]. Needs AFS confirmation: probe type for hot melt, high-temperature probe design, optical configuration and window.

**Spectral range.** NIR: 780-2500 nm nominal [S01 p.10]; MIR (ATR): 4000-400 cm-1 (2.5-25 um) nominal [S01 p.9]; Raman: Raman shift in cm-1; signal 400-1100 nm nominal [S01 p.11] (Excitation not chosen; 785 nm appears only in the S01 p.15 example). Specify only the usable range of the selected instrument and fiber; do not pick an optimal band without sample spectra.

### Risks and uncertainty

- A change of API or polymer can invalidate a calibration [DOCX §5].
- Temperature and scattering changes can mimic composition changes [DOCX §5].
- Neither a single method nor a combination is guaranteed to detect the API change [DOCX §5].
- Accuracy, update rate, temperature rating and equipment compatibility are unconfirmed. *(assumption)*
- ATR contact and fouling matter; a cleaning-compatible probe design is unconfirmed [DOCX §5].

### First feasibility experiment

1. Multi-method lab screening on representative melt samples to find API signal, optical state and range.
2. Record spectra from each candidate with time-aligned offline API reference samples from the melt.
3. Single-method models first; validate on held-out runs; combine only if it beats the best single method.
4. Compare prediction error, bias and ability to follow composition changes against agreed requirements, including build-up tolerance.

**Decision basis.** Agree accuracy, bias and response targets before testing; choose the simplest setup meeting them on independent melt runs.
