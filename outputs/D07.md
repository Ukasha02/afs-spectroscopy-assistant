# D07 · First technical assessment

**Decision status.** Provisional feasibility assessment. API identity, level and melt optics are open; a comparison plan is needed.

**Requirements stated.** Hot polymer extrusion with an API; Question: can optics detect composition changes during melt processing?; Offline assays available; Process interface is hot and may build up material.

**Key unknowns.** API identity and level (ppm or % w/w); Polymer formulation and melt optics; Temperature, pressure, build-up and cleaning; Offline assay accuracy, response time, budget.

### Clarification questions

1. Which API and other components, at what level (ppm or % w/w), must be distinguished?
2. Which offline assay, its uncertainty and sampling time give the reference values?
3. Which batch, bubble, temperature and residence-time changes must the measurement tolerate?
4. What response time, accuracy, probe point, distance and cleaning limits apply?
5. Is the goal a production sensor or an R&D tool?

### Recommendation

- **Premise: An optical measurement can detect composition changes while the melt is being processed.** — plausible to be tested. Application slide shows NIR and MIR-ATR probes for API control in hot polymer extrusion [S02 p.14]. Reason to test; melt detectability untested. *(assumption)*
- **Premise: Offline assays can serve as the reference for the optical method.** — unverifiable. Assay accuracy, precision and sampling time are unknown. *(assumption)*
- **NIR spectroscopy (Diffuse reflection probe at barrel or die).** The application example shows a NIR reflection probe at the extruder die for API in hot polymer [S02 p.14]. Diffuse reflection suits scattering media; melt optics are unknown and need lab testing [S01 Table 1 (p.6)].
- **MIR spectroscopy (ATR) (Diamond ATR probe with PIR-fiber FTIR).** The same example shows a diamond ATR probe with PIR-fiber FTIR for API in hot polymer [S02 p.14]. ATR depth is only 1-6 um, so contact and build-up matter; fiber link undefined [S01 Table 1 (p.6); S02 p.6].

**Measurement concept.** NIR diffuse reflection probe; diamond ATR probe as comparison [S01 Table 1 (p.6); S02 p.14]. Extrusion interface; exact point and access open. Silica covers NIR to 2.4 um; MIR can use PIR fiber (3-17 um), among other partial-range fibers [S02 p.6]. Link undefined; NIR: indium or zirconium fluoride fibers cover it; MIR: none covers it fully [S02 p.6]. No fiber link stated. Rule check: NIR full range: Indium fluoride fiber, Zirconium fluoride fiber; partial: UV-Vis silica fiber (standard or Al/Cu-coated), Vis-NIR silica fiber (standard or Al/Cu-coated), Chalcogenide As-S IR fiber (CIR), Hollow glass waveguide (HWG); MIR full range: no single fiber; partial: Chalcogenide As-S IR fiber (CIR), Polycrystalline silver halide IR fiber (PIR), Hollow glass waveguide (HWG), Indium fluoride fiber, Zirconium fluoride fiber [S02 p.6]. Needs AFS confirmation: probe type and window material, installation point and access, optics and fiber length.

**Spectral range.** NIR spectroscopy: 780-2500 nm nominal [S01 p.10]; MIR spectroscopy (ATR): 4000-400 cm-1 (2.5-25 um) nominal [S01 p.9]. Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- A change of API, polymer or formulation can invalidate the calibration [DOCX §5].
- Physical variation of the melt may mimic composition changes; to be tested. *(assumption)*
- Neither NIR nor ATR is guaranteed to detect the API in this melt. *(assumption)*
- Accuracy, response time, interface ratings and equipment compatibility are unconfirmed. *(assumption)*
- Contact and fouling can affect MIR-ATR; heat and cleaning effects need testing [DOCX §5].

### First feasibility experiment

1. Prepare melt samples across the agreed API range and batch, bubble, temperature and build-up variation.
2. Record NIR and ATR spectra on the same samples with timed offline assay values.
3. Build single-method models first; validate on held-out batches before any combination.
4. Compare prediction error, bias and ability to follow composition changes against client requirements.

**Decision basis.** Agree accuracy, response time and maintenance targets with the client before the trial; choose the simplest probe meeting them on held-out batches.
