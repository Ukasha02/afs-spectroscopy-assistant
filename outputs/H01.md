### Recommendation

- **Premise contradicted:** The existing NIR calibration can be reused for the new API and excipient blend [S01 p.10].
- **Premise contradicted:** Adding Raman will keep the old NIR calibration valid [S01 p.15; S01 p.12].
- **NIR (new calibration) (diffuse reflection probe).** The feed-frame blend-potency example uses NIR reflection [S01 p.15]. Overlapping NIR bands suggest chemometrics; a model should be checked on the new blend [S01 p.10].
- **Raman (Raman fiber probe (contact)).** The same example uses a contact Raman probe [S01 p.15]. Fluorescence may dominate the Raman signal; check signal quality first [S01 p.11].
- **NIR + Raman (two probes or combi probe at the same spot).** The example reports complementary NIR and Raman information for feed-frame blends [S01 p.15]. Only after each method is assessed alone; a gain is a hypothesis to test [S01 p.7].

**Measurement concept.** NIR diffuse reflection probe for powder; Raman probe as comparison [S01 Table 1 (p.6)]. Tablet press feed frame, where the NIR pilot measures. No fiber link stated; silica fibers suit UV/Vis, NIR and Raman, while MIR needs IR fibers [S02 p.6]. Needs AFS confirmation: Probe type and geometry, Feed-frame installation, Same-spot optical configuration.

**Spectral range.** NIR: 780–2500 nm nominal [S01 p.10]; Raman: Raman shift in cm-1; signal at 400–1100 nm nominal [S01 p.11] (Feed-frame example: 785 nm excitation). Usable range depends on the selected instrument and fiber; no optimal band without sample spectra.

### Risks and uncertainty

- The new formulation may affect the existing calibration; verify before reuse. *(general knowledge)*
- Particle size, density and flow can mimic API changes. *(general knowledge)*
- Neither Raman nor fusion is guaranteed to beat NIR alone [S01 p.7].
- Accuracy, update rate, ratings and compatibility are unconfirmed. *(assumption)*
- The published example is a reason to test, not proof [S01 p.15].

### First feasibility experiment

1. Prepare new-blend samples across the agreed API range and particle size, density, flow variation.
2. Record NIR and Raman spectra with time-aligned independent API reference assays.
3. Build single-method models first, fusion only if justified; validate on held-out batches [S01 p.15].
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria before testing; choose the simplest configuration meeting them on independent batches.
