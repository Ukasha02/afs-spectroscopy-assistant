### Recommendation

- **Premise contradicted:** The existing NIR calibration can be reused for the new API and excipient blend [DOCX §5].
- **Premise contradicted:** Adding Raman will keep the old calibration valid [DOCX §5; S01 p.15].
- **NIR spectroscopy (diffuse reflection probe in the feed frame).** The tablet press feed-frame example uses an NIR reflection probe for API blend potency [S01 p.15]. A new calibration must be built and validated for the new blend [DOCX §5].
- **Raman spectroscopy (Raman fiber probe in the feed frame).** In the same feed-frame example, Raman with 785 nm excitation is part of the combined NIR and Raman setup [S01 p.15]. Fluorescence can overlap Raman bands for many organic compounds, so background should be checked [S01 p.11].
- **NIR + Raman (same-spot combi probe or synchronised probes).** The feed-frame example reports higher accuracy and robustness for fused NIR and Raman models; this is one example [S01 p.15]. Only after each method is assessed alone; the gain is a hypothesis to test [S01 p.7].

### Risks and uncertainty

- A new API and excipients may invalidate the old calibration and require recalibration [DOCX §5].
- Particle size, density and flow changes can mimic API changes [DOCX §5].
- Neither Raman nor a combination is guaranteed to help [S01 p.7].
- Accuracy, update rate and equipment compatibility are unconfirmed. *(assumption)*

### First feasibility experiment

1. Prepare new-blend samples across the client-agreed API range and relevant particle, density and flow variation.
2. Record NIR, and Raman if justified, with time-aligned independent API reference assays.
3. Build a new NIR model first; Raman or fusion only if justified; validate on held-out batches.
4. Compare prediction error, bias and ability to follow changes against client requirements.

**Decision basis.** Agree numerical acceptance criteria before testing; choose the simplest configuration meeting them on independent batches.
