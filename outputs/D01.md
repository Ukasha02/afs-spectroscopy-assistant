# D01 · First technical assessment

**Decision status.** Provisional feasibility assessment. Supported feed frame application; API formulation and mechanical constraints require confirmation.

**Requirements stated.** Powder blend with API and excipients; Lab check results arrive after powder passes through the press; Assess in-line feed frame measurement of API concentration changes; Pilot should compare options before buying equipment.

**Key unknowns.** API and excipients, concentration range, acceptance limits; Reference assay uncertainty and turnaround time; Particle size, density, and flow variations; Feed frame clearance, access, and cleaning requirements.

### Clarification questions

1. Which API, excipients, and concentration range must be tracked?
2. Which reference assay, uncertainty, and sampling delay apply?
3. Which particle size, density, and flow changes occur between batches?
4. What response time, acceptance limits, and cleaning conditions apply?
5. What distance separates the press from the prospective analyzer location?

### Recommendation

- **NIR spectroscopy (diffuse reflection probe).** Supports NIR reflection for powder blend concentration [S01 p.14-15]. A matrix-specific calibration must be built and tested [S01 p.10].
- **Raman spectroscopy (Raman probe).** Supports Raman as a comparison candidate for blend potency [S01 p.14-15]. Check fluorescence background and signal quality [S01 p.11].
- **NIR + Raman combi spectroscopy (combined reflection / Raman probe).** A combi probe captures complementary vibrational data at the same spot [S01 p.15]. Assess single methods first; combination gain is a hypothesis to test [DOCX §5].

**Measurement concept.** Diffuse reflection probe for NIR and Raman probe, or a combined NIRaman probe [S01 Table 1 (p.6); S01 p.15]. Inserted directly into the tablet press feed frame [S01 p.15]. Vis-NIR silica fibers isolate spectrometers from press vibration [S01 p.15; S02 p.6]. Needs AFS confirmation: Probe dimensions and mounting flange, Clearance to moving paddles, Window material and anti-fouling geometry.

**Spectral range.** NIR spectroscopy: 780–2500 nm nominal [S01 p.10]; Raman spectroscopy: 400–1100 nm (Raman shift in cm-1) nominal [S01 p.11] (Excitation wavelength (e.g. 785 nm) stated separately from Raman shift). Specify only the usable range of the selected instrument and fiber; do not pick an optimal band without sample spectra.

### Risks and uncertainty

- API or excipient changes invalidate multivariate calibrations [S01 p.10].
- Particle size and density changes alter scattering [S01 p.10].
- Combining methods is not guaranteed to improve accuracy [DOCX §5].
- No accuracy, update rate, or mechanical fit is confirmed. *(assumption)*

### First feasibility experiment

1. Prepare representative blends across API range and physical variation.
2. Record spectra from each candidate together with independent reference assays and timing information.
3. Build single-method models first; validate on independent batches.
4. Compare prediction error and tracking ability against client requirements.

**Decision basis.** Agree numerical acceptance criteria with client before testing; choose the simplest configuration meeting them on independent material.
