# AFS Spectroscopy Assistant

An AI assistant that helps an Art Fiber Systems (AFS) expert make a first technical assessment of a new customer enquiry for in-line process spectroscopy. It reads a natural-language use case and returns:

1. Process requirements and constraints
2. Clarification questions
3. Recommended spectroscopy method(s) and spectral ranges
4. A high-level fiber-probe / measurement concept
5. Reasoning, limitations and uncertainty, with citations to AFS materials
6. A short first feasibility-study plan

Built for **Challenge 01** of the SchubKI National AI Hackathon 2026, with Art Fiber Systems as the challenge partner.

> Status: 🚧 in development. See [docs/PRD.md](docs/PRD.md).

## Contributing

- **One branch per feature** (`feat/kb-parsing`, `fix/citations`, …). Open a PR into `main`, and don't push directly to it.
- Keep the setup instructions in this README working at all times, because reproducibility is a submission requirement.
- **Never commit secrets** (`.env` is gitignored) or the AFS materials.
- **H01–H06 outputs must be generated by the assistant.** Don't edit them by hand or add logic for a specific case.
